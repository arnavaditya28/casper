# 60-second demo script

Record with **OBS Studio** or **Clipchamp** (built into Windows 11), both free. Use 1080p and capture system audio so CASPER's voice is in the video.

| Time | You do / say | What viewers see |
|---|---|---|
| 0:00 | Open CASPER from the tray | The greeting: “Good evening… it's 24 degrees…” and the aurora background |
| 0:06 | “Hey Casper, search best laptop under 60k” | The 3D orb swirls, results with the BEST MATCH badge |
| 0:14 | “Compare the top 3” | Local AI answers from the results |
| 0:20 | Click **Why #1?** on the Search page | The ranking breakdown bars, plus the Wikipedia card |
| 0:26 | “Doosra wala kholo” | The second result opens: Hinglish works |
| 0:31 | “YouTube pe lofi chalao” | A real video starts playing |
| 0:37 | “Coding layout” | VS Code snaps left, Chrome right |
| 0:42 | “What's on my screen?” | CASPER reads and explains the screen |
| 0:48 | “Pomodoro for 25 minutes” | Distractions close, the focus ring starts |
| 0:53 | “Quiz me on space” → “B” | Quiz card, “Correct!”, an achievement toast |
| 0:58 | Open the Privacy page | Privacy score, trackers stripped, 0 B audio uploaded |

**Tips:** turn on Ghost mode before recording if you don't want your real history visible. Set your name in Settings → You for the greeting.
